# Oráculo Web Clipper

1. Abra a página de extensões do Chrome ou Edge.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação** e selecione a pasta **browser-extension**.
4. Mantenha o Oráculo aberto e autenticado em http://127.0.0.1:8765.

O conteúdo capturado sempre abre uma revisão no Oráculo. Nada é anexado ao chat ou enviado ao modelo automaticamente.
